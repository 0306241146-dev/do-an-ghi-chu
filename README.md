Hệ thống quản lý ghi chú và thông tin riêng tư (NoteVault)

1. Yêu cầu hệ thống
- Cài đặt Node.js phiên bản 16+ trở lên
- Trình duyệt web (Google Chrome, Microsoft Edge, Brave,...)
2. Hướng dẫn khởi động dự án
a. Hướng dẫn chạy backend
- Chuyển vào thư mục backend: cd backend
- Cài đặt thư viện: npm install
- Khởi chạy máy chủ: node server.js
*Backend chạy tại cổng: http://localhost:5000
b. Hướng dẫn chạy Frontend
- Chuyển vào thư mục frontend: cd frontend
- Cài đặt các thư viện: npm install
- Cài đặt bộ icon Lucide: npm i lucide-react
- Khởi chạy giao diện: npm run dev
*Frontend chạy tại cổng: http://localhost:5173
Ghi chú thêm:
- Hệ thống sử dụng file JSON để lưu dữ liệu tại thư mục 'backend/data', vui lòng không xóa thư mục này.
